NEXTTALENTGLOBAL WEBSITE - VERCEL DEPLOYMENT

Static HTML, CSS and JavaScript website. Import this folder in Vercel; no build step is needed. GSAP 3.15.1 and ScrollToPlugin load from the jsDelivr CDN. The Vercel configuration adds a Content Security Policy and standard security headers.

BEFORE LAUNCH
- Confirm the operating business's full legal name and postal address; add them to the privacy notice.
- Confirm intended governing law and court location with the operating business/counsel, then update the terms page.
- The contact form is a front-end demo and does not send submissions. Connect and test a form provider/backend before inviting enquiries, then update the privacy notice with its data handling.
- Review company and service descriptions.

The site currently uses one first-party cookie to remember acknowledgment of the cookie notice. It does not use analytics or advertising cookies.
